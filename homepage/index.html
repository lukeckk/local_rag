Local RAG

Quick Start

Start the stack, upload a document, and ask your first question.

Open App
Need Docker + Ollama
Model llama3.2:3b
App localhost:8502
1

Install the basics

Make sure Docker Desktop and Ollama are running.

ollama pull llama3.2:3b
2

Start the app

Use a repo-relative path (not a machine-specific username path):

git clone <your-repo-url>
cd rag_documents
docker compose up -d --build

If you publish prebuilt images, users can skip local builds:

docker compose pull
docker compose up -d
3

Open the tools

Frontend localhost:8502 Backend health localhost:8001/health Qdrant localhost:6335/dashboard
4

Use it

  1. Upload a PDF, CSV, spreadsheet, or text file.
  2. Click Process & Index.
  3. Ask a question about the file.
