Local RAG

Full Privacy AI Chat for Your Documents

100% local, free to run, and usable without external AI APIs. Your files stay on your machine.

🐙 GitHub Open App
1

Install the basics

Install Docker Desktop and Ollama first, then make sure both are running.

# Install Docker Desktop:
# https://www.docker.com/products/docker-desktop/

# Install Ollama:
# https://ollama.com/download
2

Start the app

Clone the repository and run the app from the project folder:

git clone https://github.com/lukeckk/local_rag.git
cd rag_documents
ollama pull llama3.2:3b
docker compose up -d --build
3

Open the tools

Frontend localhost:8502 Backend health localhost:8001/health Qdrant localhost:6335/dashboard
4

Use it

  1. Upload a PDF, CSV, spreadsheet, or text file.
  2. Click Process & Index.
  3. Ask a question about the file.

Quick fixes

  • No model answerollama serve
  • Page looks staleCmd + Shift + R
  • Reset everythingdocker compose down -v
  • Check backend logsdocker logs doc_backend
