LOCAL RAG

Get Started in Minutes

This page walks new users through setup, startup, and first query for this local document RAG app.

1) Prerequisites

  • Docker Desktop installed and running
  • Ollama installed locally
  • Model pulled in Ollama: llama3.2:3b
ollama pull llama3.2:3b

2) Start the App

From any location, run:

cd /Users/lukecheng/rag_documents
docker compose up -d --build

# Or as a one-liner:
cd /Users/lukecheng/rag_documents && docker compose up -d --build

3) Open Services

  • Frontend: http://localhost:8502
  • Backend Health: http://localhost:8001/health
  • Qdrant Dashboard: http://localhost:6335/dashboard

4) First-Time Usage

  1. Go to the sidebar and upload a file (PDF, CSV, XLSX, XLS, or TXT).
  2. Click Process & Index.
  3. Ask questions in chat about the uploaded content.
  4. Use Indexed Files to delete individual files from vector storage.

5) Troubleshooting

  • No answer from model: ensure Ollama is running on your host.
  • Changes not visible: hard refresh browser or restart relevant container.
  • Clean reset: docker compose down -v then start again.

Need help? Check container logs with docker logs doc_backend.
